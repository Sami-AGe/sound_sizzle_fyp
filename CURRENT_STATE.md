## ✅ Task I — Migrate Stage 2 LLM: Groq → Gemini (DONE)

**Why:** Groq's `openai/gpt-oss-120b` had an 8K TPM hard cap per request. Every storyboard
call hit it (8417 tokens > 8000 limit). Even after Bug 17 trims it still risked 413 errors.
Gemini 2.0 Flash: 1M TPM, 32K per request, 1500 req/day — 413 becomes impossible.
Quality is better for structured creative JSON. Native JSON mode eliminates "Unterminated string"
truncation failures permanently.

**Model used:** `gemini-3.8-flash` (free tier, no credit card required)
API key: Added to `.env` as `GEMINI_API_KEY` (from https://aistudio.google.com/apikey)

### Implementation completed:
1. **SDK installed:** `google-generativeai` v0.8.6 in venv
2. **Client replaced:** `from groq import Groq` → `import google.generativeai as genai`
3. **Both API calls replaced:**
   - `generate_character_anchor()` — uses `model.generate_content()` with `response_mime_type="application/json"`
   - `generate_storyboard()` — uses `model.generate_content()` with `response_mime_type="application/json"`
4. **Parameters updated:** `max_tokens=5500` → `max_output_tokens=8192` (removed TPM limit)
5. **Native JSON mode:** `response_mime_type="application/json"` ensures structured output
